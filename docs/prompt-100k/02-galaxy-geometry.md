# 第二卷　银河系几何、采样与光带视角规格

> 本卷把第一卷的科学参数变成可编码的几何。目标不是"看上去像一张银河图片"，而是"每一个亮点都能说出它为什么在那里"。所有采样函数都以世界单位 wu 为输入输出，默认银河层映射为 1 wu = 20 光年，盘半径 R_gal = 2500 wu。

---

### 2.1 几何总览与绘制顺序

银河层由一个三维粒子系统、一层盘面纹理、一层暗尘粒子、一层背景星空和若干标记组成。绘制顺序必须固定，否则透明混合与暗尘遮挡会出错：

1. 清屏，绘制远景星空（不随银河旋转）。
2. 绘制银晕粒子（最暗、最远、先画）。
3. 绘制厚盘粒子。
4. 绘制薄盘与旋臂粒子。
5. 绘制核球与中央棒粒子。
6. 绘制 HII 区与亮星团（加色混合）。
7. 绘制暗尘带（使用反向混合或乘法混合，压暗背景）。
8. 绘制盘面纹理（可选，低强度叠加）。
9. 绘制太阳标记、恒星系统标记、旋臂标签。
10. 绘制 UI 标签层（HTML 或 canvas 覆盖层）。

粒子系统按"层"拆成多个缓冲区，而不是全部塞进一个 VBO。原因有三：不同层需要不同的点尺寸与混合模式；低画质模式可以整层关闭（如银晕、暗尘）；拾取与调试时可以单独统计每层粒子数。推荐缓冲区划分：

- `bufHalo`：银晕与球状星团，约 8% 粒子。
- `bufThick`：厚盘，约 10%。
- `bufThin`：薄盘场星，约 30%。
- `bufArm`：旋臂增强粒子，约 34%。
- `bufBulge`：核球与中央棒，约 12%。
- `bufHII`：HII 区与年轻星团，约 4%。
- `bufDust`：暗尘，约 2%（单独按密度上限生成）。
- `bufBg`：背景星空，独立于银河，不参与旋转。
- `bufLocalGroup`：本星系群其他星系，独立缓冲区，L-1 层使用。

总粒子数在默认画质下建议 40 万–60 万；现有 34 万可以提升到 45 万，并把每个粒子的属性从 4 个 float 扩展到 8 个 float（位置 xyz、颜色 rgb、尺寸、亮度），以支持更真实的颜色与点尺寸变化。低画质模式按 35% 比例降采样，但保留核球与中央棒的密度，避免低画质下"银河没有中心"。

### 2.2 中央棒：银河系的骨架

中央棒是 SBbc 的识别特征。它不是一个矩形块，而是一个三轴椭球，长轴沿棒方向，中轴与短轴较短。建模参数：

- 半长轴 a_bar = 4.2 kpc = 13,700 光年 = 685 wu。
- 半宽 b_bar = 1.0 kpc = 3,260 光年 = 163 wu。
- 半厚 c_bar = 0.7 kpc = 2,280 光年 = 114 wu。
- 方位角 θ_bar = 25°，即棒的长轴相对世界 X 轴绕 Y 轴旋转 25°。
- 密度分布：沿长轴用指数或高斯衰减，沿短轴与厚度方向用高斯衰减。

棒内采样采用"拒绝采样 + 椭球变换"：

```
u = random(-1, 1)
v = random(-1, 1)
w = random(-1, 1)
if (u*u + v*v + w*w > 1) reject
x_bar = u * a_bar * s
y_bar = w * c_bar * s
z_bar = v * b_bar * s
```

其中 s 取 0.9–1.1 的随机缩放，制造边缘的不规则。然后把 (x_bar, z_bar) 绕 Y 轴旋转 θ_bar：

```
x = x_bar * cos(θ) + z_bar * sin(θ)
z = -x_bar * sin(θ) + z_bar * cos(θ)
```

颜色上，棒内的恒星偏年老：色温 4500–6000 K，RGB 约 (1.00, 0.83, 0.62) 到 (1.00, 0.92, 0.80)，少量偏红的 (1.00, 0.72, 0.50)。亮度分布建议中心亮、两端稍暗，但不能像核球那样亮；棒的两端要有"渐隐"，避免看起来像一根发光棒棒糖。尺寸上，棒内粒子略大于场星（1.2–1.6 倍），以形成连续的亮带。

为了让棒"看起来像棒"而不是一团椭圆，棒内还需要一层沿长轴的细亮脊：约 15% 的棒粒子沿 v、w 接近 0 的区域集中，形成中央亮线。这些粒子的颜色略偏黄白，尺寸略小，亮度略高。这样在俯视和侧视时，都能看到一条贯穿核球的亮轴。

### 2.3 核球：花生状而不是鸡蛋形

核球半径约 1.2 kpc = 3,900 光年 = 195 wu。它不是标准椭球，而是被棒贯穿的"花生状"（peanut-shaped）结构，部分模型还包含 X 形轮廓。实现上采用三层叠加：

第一层，宽椭球：半轴 (195, 135, 165) wu，密度按 exp(-r²/2) 衰减，颜色偏黄橙，提供核球的基础亮度。

第二层，沿棒方向的窄分量：半轴 (260, 90, 100) wu，密度更高、衰减更快，颜色偏黄白，勾勒出棒的内部轮廓。这一层与 2.2 节的棒使用同一方位角，但尺度更小，避免棒与核球脱节。

第三层，X 形分量（可选，高画质开启）：在核球中心附近，沿两条与棒约成 ±35° 的斜轴，放置少量高亮度粒子，形成"X"或"蝴蝶"轮廓。这部分不是所有观测都支持，默认强度较低，可通过配置关闭；在信息面板中注明"X 形核球结构仍有争议"。

核球中心需要叠加一个屏幕空间辉光，而不是只靠粒子密度。辉光用一个大尺寸、低亮度的点精灵或后处理 bloom 实现，半径约 40–60 像素，颜色 (1.0, 0.85, 0.65)，强度随相机距离衰减。注意：辉光不能遮住人马座 A* 的标记，也不能让核球看起来像一个行星。

核球的垂直尺度要明显大于薄盘：在侧视图中，核球应像一个鼓起的小包子，中央棒在包子内部若隐若现。如果侧视图里核球和盘一样薄，说明垂直分布写错了。

### 2.4 银盘：指数盘、薄盘与厚盘

薄盘的径向表面密度用指数盘近似：

```
Σ(R) = Σ0 * exp(-R / h_R)
```

其中 h_R 取 3.5 kpc = 11,400 光年 = 570 wu。这与观测到的银河系盘尺度长度（约 2.5–3.5 kpc）一致。径向范围从 0.8 kpc 到 15 kpc（260–4,900 wu），外侧在 15 kpc 之外快速截断，形成可见的边缘。视觉上，盘的外缘不能是硬切的圆形，要用 0.5–1 kpc 的渐隐带。

垂直分布按薄盘与厚盘分开：

- 薄盘：标高 h_z = 0.3 kpc = 980 光年 = 49 wu，占总盘粒子的 70%。
- 厚盘：标高 h_z = 1.2 kpc = 3,900 光年 = 195 wu，占 30%。

薄盘的垂直采样用高斯分布，但要做"截断"：|y| 超过 3h_z 的粒子重采样，避免极端离群点。厚盘同样用高斯，但分布更宽、颜色更黄、亮度更低。厚盘的存在感在侧视图中尤其重要：它会让盘面边缘呈现柔和的雾状，而不是一条硬线。

盘内粒子的角向分布不能是均匀的。真实盘有旋臂、臂间空隙、局部恒星群。基础盘（场星）可以均匀采样，但需要用旋臂密度函数做调制：落在旋臂内的粒子亮度提高、颜色偏蓝；落在臂间的粒子亮度降低、颜色偏黄。具体增强函数见 2.5 节。

盘的中心厚度与边缘厚度不同：中心区域受核球影响，视觉厚度约 1 万光年（500 wu）；边缘逐渐变薄到 3,000–4,000 光年（150–200 wu）。实现上，薄盘的标高可以写成半径的函数：

```
h_z(R) = h_edge + (h_center - h_edge) * exp(-R / R_taper)
```

其中 h_center = 49 wu（薄盘中心略厚），h_edge = 18 wu，R_taper = 800 wu。这个函数只影响视觉厚度，不改变密度归一化。

### 2.5 四条主旋臂：从棒端出发的对数螺旋

旋臂用对数螺旋建模：

```
r(θ) = r0 * exp(b * (θ - θ0))
```

其中 b = tan(p)，p 为螺距角。默认 p = 13°，b ≈ 0.2309。旋臂不是从原点出发，而是从棒的末端出发：r0 取 4.2 kpc（685 wu），θ0 为棒端的方向角。

四条主旋臂的相位与参数如下（角度以世界 XZ 平面、从 +X 轴逆时针为正）：

| 旋臂 | 中文名 | 起始角 θ0 | 螺距角 p | 强度 | 颜色倾向 |
|---|---|---|---|---|---|
| Arm 1 | 英仙臂 | 25° + 0° | 13° | 1.00 | 蓝白 + 粉紫 |
| Arm 2 | 人马—船底臂 | 25° + 90° | 14° | 0.95 | 蓝白 + 粉紫 |
| Arm 3 | 矩尺臂 | 25° + 180° | 15° | 0.55 | 黄白（内侧较年老） |
| Arm 4 | 盾牌—半人马臂 | 25° + 270° | 12.5° | 0.90 | 蓝白 + 粉紫 |

注意：四条臂不是完全对称的。英仙臂与人马臂最显著，矩尺臂较暗，盾牌—半人马臂较宽。幅度差异用强度系数控制；相位差也不必严格 90°，可以在 ±8° 内随机偏移，避免"风车"感。起始半径也应有差异：内侧两条臂从 3.8 kpc 起，外侧两条从 4.5 kpc 起。

旋臂的采样方式有两种，推荐混合使用：

**方式 A：极坐标直接采样。** 对每条臂，沿 θ 从 θ0 到 θ_max（约 2.2π），按 r(θ) 计算中心线，再在中心线两侧加入高斯扰动：

```
r_sample = r(θ) + gaussian(0, w_arm)
θ_sample = θ + gaussian(0, w_theta)
```

其中 w_arm ≈ 0.6–1.0 kpc（30–50 wu），w_theta ≈ 0.05–0.08 rad。这种方式的粒子严格沿臂分布，适合生成清晰的旋臂骨架。

**方式 B：盘内拒绝采样。** 先在盘内均匀采样 (R, θ)，计算该点到最近旋臂中心线的距离 d_arm，用概率 p = exp(-d_arm² / (2w²)) 接受。这种方式会自然形成臂间场星，但效率较低。推荐用方式 A 生成 70% 的臂粒子，用方式 B 生成 30% 的臂间过渡粒子。

旋臂的颜色分层：

- 臂的中心线附近：年轻蓝白星，色温 10,000–20,000 K，RGB 约 (0.68, 0.80, 1.00)，尺寸略小、亮度略高。
- 臂的外侧：中年恒星，色温 7,000–10,000 K，RGB 约 (0.85, 0.90, 1.00)。
- 臂的内侧与臂间：年老恒星，色温 4,500–6,000 K，RGB 约 (1.00, 0.85, 0.65)。

每条臂的亮度不能均匀。真实旋臂是"团块状"的，有亮结、暗段、分支。实现上给每条臂叠加一个沿 θ 的低频噪声（1–2 个正弦波或 fBm），让亮度在 0.5–1.3 倍之间起伏；再叠加少量高频亮结（HII 区），形成"串珠"效果。

旋臂宽度随半径变化：内侧较窄（0.5–0.7 kpc），外侧较宽（1.0–1.5 kpc），符合观测到的旋臂张开趋势。实现上让 w_arm(R) 随 R 线性增加，从 30 wu 到 60 wu。

### 2.6 猎户臂与太阳附近的结构

猎户臂是太阳所在的次级臂段，位于人马臂与英仙臂之间。它的建模不能简单复制一条主旋臂，因为：

第一，它较短：长度约 5–8 kpc，视觉上不应绕满一圈。第二，它较细：宽度约 0.4–0.6 kpc，粒子密度低于主旋臂。第三，它有一个"分支"结构：靠近太阳处有若干短刺（spur），如天鹅座支臂。第四，太阳位于它的内缘，而不是中心线。

建模参数：

- 起始点：在世界坐标中，太阳位于 (R=1335 wu, θ=2.30 rad)。猎户臂的中心线应经过太阳附近，但在太阳的外侧约 100–150 wu 处，使太阳处于内缘。
- 长度：沿对数螺旋延伸约 1.5–2.0 rad，视觉长度约 800–1000 wu（1.6 万–2 万光年）。
- 宽度：30–45 wu（600–900 光年）。
- 亮度：主旋臂的 0.45–0.6 倍，颜色以蓝白为主，夹杂少量粉紫 HII 区。
- 分支：在猎户臂的两侧添加 2–3 条短刺，长度 100–250 wu，角度与主臂成 20°–40°。

太阳标记必须放在猎户臂内缘，且要有明显的视觉区分：一个带脉冲光环的小黄点，旁边是"太阳系"标签。标记不能淹没在旋臂粒子中，因此需要在粒子之后绘制，并用屏幕空间的最小尺寸保证可见性。

太阳附近还应有一个"本地泡"效果：一个半径约 100 pc（16 wu）的低密度区域，粒子密度略低，颜色略暗。这不是必须的，但能解释为什么太阳附近看不到密集的星云。低画质下可以省略。

### 2.7 暗尘带：真实感的另一半

没有暗尘带的银河系像一张过度曝光的照片。暗尘带沿旋臂内侧分布，由冷分子云和尘埃组成，遮挡背后的星光。视觉上表现为褐色/黑色的不规则丝状纹理。

实现方式：单独一层粒子，使用反向混合（`blendFunc(ZERO, ONE_MINUS_SRC_ALPHA)` 或等效的乘法混合），颜色为暗褐 (0.05, 0.03, 0.02)，透明度 0.15–0.45。粒子沿旋臂中心线的内侧偏移 0.2–0.5 kpc，宽度 0.2–0.4 kpc，沿臂呈团块状分布。

暗尘带的关键细节：

- 不能均匀覆盖整条旋臂，要有"断带"和"浓云"。用 1–2 层 fBm 噪声调制透明度，噪声尺度约 0.3–0.8 kpc。
- 在核球前方（靠近相机一侧）也要有暗尘，形成"大裂缝"（Great Rift）效果。大裂缝是银河光带中间那条明显的暗带，从天鹅座延伸到人马座，是内部视角最重要的识别特征。
- 暗尘粒子的尺寸应比星光粒子大 2–4 倍，但透明度低，形成柔和的遮挡，而不是黑色斑点。
- 暗尘不能完全遮挡核球，否则中心会变成一个黑洞。核球区域的暗尘强度要降低 50%。

低画质模式可以关闭暗尘层，但必须在图例中说明"低画质已关闭暗尘带"，避免用户以为模型出错了。

### 2.8 HII 区、星团与恒星形成区

HII 区是电离氢区，呈粉红色/洋红色，常出现在旋臂的亮结处。它们是银河系照片中最醒目的彩色斑点。建模规格：

- 数量：默认 300–600 个，沿四条主旋臂与猎户臂分布。
- 尺寸：每个 HII 区由 20–80 个粒子组成，整体半径 5–25 wu（100–500 光年）。
- 颜色：核心 (1.00, 0.45, 0.65)，外围 (0.85, 0.35, 0.75)，少量偏蓝的电离区 (0.60, 0.55, 1.00)。
- 亮度：高于普通星点 2–4 倍，使用加色混合。
- 位置：优先放在旋臂中心线两侧 ±0.3 kpc 内，并沿臂成串分布，而不是随机撒点。

疏散星团与年轻星团：用少量蓝色亮点的聚集表示，每个星团 10–30 个粒子，半径 2–6 wu。它们与 HII 区位置相关，但不完全重合。球状星团属于银晕，不在旋臂中，颜色偏黄，尺寸更小，数量约 160 个。

### 2.9 银晕、球状星团与恒星流

银晕的粒子分布近似球状，密度按幂律衰减：

```
ρ(r) ∝ r^(-3)
```

半径范围 15–100 kpc（750–5,000 wu），但为了避免粒子过多，实际采样限制在 750–3,500 wu，外层用极低密度点缀。颜色偏黄白 (1.00, 0.88, 0.70)，亮度低，尺寸小。

球状星团：160 个左右，每个由 8–20 个粒子组成，整体半径 3–8 wu，颜色偏黄，亮度略高于银晕场星。位置按球状分布，避免集中在盘面。部分球状星团可以在信息面板中标注名称，如 M13、半人马座 ω、47 Tucanae。

恒星流：用 3–5 条细长的带状采样表示，长度 200–800 wu，宽度 5–15 wu，亮度极低。它们代表被潮汐撕裂的矮星系残骸，视觉上像淡淡的弧线。默认画质下可以只保留 1–2 条，高画质下开启全部。

银晕与银盘的边界不要做成硬切。在半径 10–20 kpc 之间，让盘粒子密度逐渐降低，银晕粒子密度逐渐升高，形成自然的过渡。

### 2.10 背景星空与银河光带

背景星空是"无限远"的装饰层，不随银河旋转。它由 8,000–15,000 个暗弱点组成，颜色从冷白到淡黄，亮度低，尺寸 1–2 像素。背景星空的分布应尽量均匀，但可以加入一条极暗的"银河带"——这不是银河系盘本身，而是从太阳系看到的银河光带的远景提示。注意：在银河层的外部视角中，背景星空只是背景，不应与银河盘混淆；在"从太阳看银河"的视角中，银河盘本身会形成光带，此时背景星空应更暗、更稀疏。

光带视角的相机规格：

- 相机位置：太阳附近，世界坐标 (1335, 3.25, 0) 附近（按太阳方位角旋转）。
- 朝向：沿银道面看向银心方向，或沿盘面切线方向。看向银心时光带最亮、最宽；沿切线方向时光带横贯视野，层次最丰富。
- 视场角：fov = 70°–90°，模拟人眼的宽视野。
- 相机高度：贴近盘面（y ≈ 3–20 wu），略高于盘面，能看到光带的上下边缘。
- 近远裁剪面：near = 0.5，far = 20,000，确保能看到远处的盘和核球。
- 曝光：内部视角的粒子亮度要整体降低 30%–50%，否则近处粒子会过曝成一片白。需要按距离做亮度衰减，近处粒子不能太亮。

光带视角的视觉目标：屏幕上出现一条横贯的亮带，中央（银心方向）明显鼓起且偏黄，两侧逐渐变细变暗，带内有暗尘裂缝，带外是稀疏的背景星。用户应该能一眼认出"这是银河"，而不是"这是一团粒子"。

### 2.11 粒子预算与性能

默认画质（high）粒子预算：

| 层 | 粒子数 | 说明 |
|---|---|---|
| 银晕 + 球状星团 | 30,000 | 球状星团占 8,000 |
| 厚盘 | 40,000 | 偏黄、较暗 |
| 薄盘场星 | 110,000 | 基础盘 |
| 旋臂 | 150,000 | 四条主臂 + 猎户臂 |
| 核球 + 中央棒 | 50,000 | 棒占 20,000 |
| HII 区 + 星团 | 15,000 | 加色混合 |
| 暗尘 | 25,000 | 反向混合 |
| 背景星空 | 12,000 | 不旋转 |
| 合计 | 432,000 | 不含本星系群 |

这个预算比现有的 34 万多约 27%，但通过以下手段保持性能：

- 粒子属性压缩：位置用 Float32，颜色用 3 个 Uint8 归一化，尺寸用 Uint8，亮度用 Uint8。每粒子 20 字节，比 8 个 Float32 的 32 字节省 37%。
- 分层 VBO，低画质整层关闭。
- 点精灵着色器不做复杂光照，只做指数衰减与能量补偿。
- 暗尘与 HII 使用较低的分辨率或较少的粒子。
- 动态降采样：根据相机距离，旋臂粒子按前缀比例绘制（`drawArrays(POINTS, 0, count*ratio)`），远处不需要全量。

性能底线：1080p、集成显卡、high 画质 ≥ 30 FPS；mid ≥ 30 FPS；low ≥ 24 FPS。若高画质达不到 30 FPS，自动降到 mid，并在角落提示"已自动降低画质"。

### 2.12 颜色与亮度规范

颜色不是装饰，而是物理编码。推荐调色板：

- 年老恒星（核球、棒、厚盘）：`#ffd9a3`、`#ffc078`、`#ffb066`，少量 `#ff9466`。
- 中年恒星（薄盘场星）：`#fff4e0`、`#ffe9c9`。
- 年轻恒星（旋臂）：`#cfe2ff`、`#a8c8ff`、`#8fb8ff`。
- HII 区：`#ff6f9f`、`#ff4f8f`、`#d96bff`。
- 暗尘：`#1a0f0a`，以低透明度混合。
- 银晕：`#ffe6b8`，低亮度。

亮度方面，核球中心最亮，但峰值亮度要有上限，避免 HDR 过曝。建议用"亮度 × 距离衰减 × 能量补偿"三因子控制，能量补偿让远处的小点仍然可见但不刺眼。相机进入盘内时，整体曝光下调，核球亮度单独限制。

### 2.13 实现步骤与伪代码

第一步：重构粒子生成器。把现有 `buildGalaxyParticles()` 拆成多个函数：`buildHalo()`、`buildThickDisk()`、`buildThinDisk()`、`buildArms()`、`buildBulge()`、`buildBar()`、`buildHII()`、`buildDust()`。每个函数返回一个 Float32Array 或 Uint8Array 缓冲区及粒子数。

第二步：建立统一随机分布工具。实现 `gaussian()`（Box–Muller）、`uniform()`、`sampleDisk()`（指数盘）、`sampleEllipsoid()`、`logSpiral()`、`fbm1d()`。所有采样使用同一个可复现的随机种子，保证每次加载的银河一致，便于截图对比。

第三步：按 2.2–2.9 节的参数生成各层。注意旋臂与太阳位置的协调：先生成旋臂中心线，再确定太阳位置，最后生成猎户臂，使太阳落在猎户臂内缘。

第四步：为每层建立独立的 VBO 与绘制调用。粒子属性按 20 字节布局：position（3×Float32）、color（3×Uint8）、size（1×Uint8）、brightness（1×Uint8）、layerFlag（1×Uint8）、padding（1×Uint8）。

第五步：实现光带视角。新增 `viewMode` 状态：`'face' | 'edge' | 'inside'`。切换时用相机补间，`inside` 模式把相机放到太阳位置附近，朝向银心，降低曝光，并隐藏外部视角的标签。

第六步：用无头截图验证三种视角。俯视图应看到棒与四条臂；侧视图应看到细长光带与鼓起的核球；内部视角应看到横贯天空的光带与暗尘裂缝。

伪代码（旋臂采样）：

```
function sampleArm(arm, n) {
  for (i = 0; i < n; i++) {
    var t = random(0, 1);
    var theta = arm.theta0 + t * arm.thetaSpan;
    var r = arm.r0 * Math.exp(Math.tan(arm.pitch) * (theta - arm.theta0));
    var jitterR = gaussian() * arm.width * (0.5 + t);
    var jitterT = gaussian() * 0.04;
    var rr = r + jitterR;
    var tt = theta + jitterT;
    var x = rr * Math.cos(tt);
    var z = rr * Math.sin(tt);
    var y = gaussian() * diskHeight(rr);
    var color = pickStarColor(t, jitterR, arm);
    push(x, y, z, color, sizeFor(color), brightnessFor(r, t));
  }
}
```

### 2.14 本卷验收标准

视觉验收：

1. 俯视图能清楚看到中央棒，棒的方向与旋臂起点一致，旋臂从棒端甩出。
2. 四条主旋臂不等亮、不等宽，猎户臂位于人马臂与英仙臂之间，太阳在猎户臂内缘。
3. 侧视图呈细长光带，核球鼓起，盘面有厚度，不是一条没有厚度的线。
4. 内部视角能看到横贯视野的银河光带，中央偏黄偏亮，带内有暗尘裂缝。
5. 暗尘带沿旋臂内侧分布，有断带与浓淡变化，不完全遮挡核球。
6. HII 区呈粉紫色，成串分布在旋臂亮结处，不随机散落。
7. 银晕呈球状分布，球状星团稀疏、偏黄，与盘面有明显区分。
8. 放大进入盘内时，粒子不会突然变成巨大的方块或过曝的白斑。

数值验收：

1. 太阳到银心的世界距离 = 1335 ± 5 wu，与 26,700 光年 ÷ 20 一致。
2. 中央棒半长轴 = 685 ± 10 wu，方位角 25° ± 1°。
3. 薄盘标高 = 49 ± 5 wu，厚盘标高 = 195 ± 10 wu。
4. 旋臂螺距角在 12°–15° 之间，四条臂的相位差在 90° ± 8° 内。
5. 总粒子数在默认画质下 40 万–50 万，低画质抽样比例 35% ± 2%。
6. 三种视角切换后，相机在 1.5 秒内稳定，不出现穿模或画面骤暗。
