# 第三卷　六级尺度层级、相机系统与下钻判定

> 用户的核心质问"为什么放大只能到太阳系"，本质上是层级设计问题，不是缩放阈值问题。本卷定义一套从本星系群到地月系的六级尺度，并给出每一级之间"如何进入、如何返回、依据什么判定"的完整规则。任何"无条件跳到太阳系"的代码都属于设计缺陷，必须删除。

---

### 3.1 六级尺度总表

新模型的层级不再是一条单线，而是一棵以"位置 + 尺度"为坐标的树。用户可以从任意尺度向外拉远、向内推进，每次推进都应该有明确的目标，而不是被硬编码到一个固定场景。

| 层级 | 代号 | 尺度范围（直径） | 主对象 | 可点击对象 | 进入方式 |
|---|---|---|---|---|---|
| L-1 | 本星系群 | 1000 万光年 | 银河系、仙女座、三角座、大小麦哲伦云 | 各成员星系 | 从银河层向外拉远，或点击"本星系群"按钮 |
| L0 | 银河系 | 10 万光年 | 银盘、棒、旋臂、太阳 | 太阳系、邻近恒星系统、旋臂标签 | 从本星系群点击银河系，或启动默认 |
| L0.5 | 恒星系统 | 0.001–10 光年 | 南门二、巴纳德星、天狼星等 | 恒星、已知行星 | 在银河层点击恒星标记，或从侧栏选择 |
| L1 | 太阳系 | 80 AU（视觉压缩） | 太阳、八大行星 | 行星、卫星、小行星带 | 点击银河层的太阳标记 |
| L2 | 地月系 | 0.005 AU（38.4 万 km） | 地球、月球 | 地球、月球、轨道 | 在太阳系聚焦地球后继续放大，或点击"地月系"按钮 |
| L3 | 行星表面 | 行星直径 | 行星表面纹理 | 表面特征（可选） | 在地月系或太阳系双击地球/行星 |

层级的唯一标识用字符串表示，例如 `localgroup`、`galaxy`、`star:alphacen`、`solar`、`earthmoon`、`planet:earth`。深链接、状态同步、返回栈都使用这套标识，禁止用数字索引，避免增删层级时错位。

### 3.2 旧状态机的问题

旧实现的状态机只有四个状态：`GALAXY`、`SOLAR`、`TRANSITION`、`PLANET_FOCUS`。它有三个结构性缺陷：

第一，下钻判定与视线无关。旧代码在 `zoomStep()` 中判断"只要当前是银河层且相机半径小于 `diveR`，就调用 `diveToSolar()`"。这意味着用户在银河的任何位置放大，都会被传送到太阳系。正确做法是：只有相机目标（或屏幕中心拾取对象）距离太阳标记足够近时，才进入太阳系；否则应该继续放大银河系本身，或进入用户指向的恒星系统。

第二，层级是单向的。旧状态机没有"本星系群"，也没有"地月系"，更没有"其他恒星系统"。用户向外拉远时，最多看到银河系的外盘，再拉远就是空背景。

第三，过渡是"换场景"而不是"连续缩放"。旧实现用 alpha 交叉淡入淡出掩盖尺度跳变，但没有比例尺提示，用户不知道自己跳了多远。新设计需要在过渡期间显示比例尺与目标名称，让跳变变成"有意义的推进"。

### 3.3 新状态机设计

新状态机的状态与旧状态机不是一一对应关系。建议把"层级"与"过渡状态"分开：

```
var LAYER = {
  LOCAL_GROUP: 'localgroup',
  GALAXY: 'galaxy',
  STAR_SYSTEM: 'star',
  SOLAR: 'solar',
  EARTH_MOON: 'earthmoon',
  PLANET: 'planet'
};

var PHASE = {
  IDLE: 'idle',
  TRANSITION: 'transition',
  FOCUS: 'focus'
};
```

`layer` 表示当前所在层级，`phase` 表示是否在过渡或聚焦。`layer` 的变化必须经过 `transitionTo(targetLayer, options)`，不允许直接赋值。`transitionTo` 负责：

1. 校验目标层级是否合法、是否已加载。
2. 保存当前相机状态与返回栈。
3. 设置过渡类型（zoom-out、zoom-in、crossfade、dive）。
4. 启动相机补间与透明度补间。
5. 在过渡结束回调中设置新的 `layer`、更新深链接、刷新 UI。

返回栈用数组保存 `{ layer, cam, focusedId, hash }`。按 `Esc` 或点击"返回"时弹出栈顶，反向播放过渡。返回栈的最大深度为 8，避免内存无限增长。

状态机的合法转移：

- `LOCAL_GROUP → GALAXY`：点击银河系，或向内缩放越过阈值。
- `GALAXY → LOCAL_GROUP`：向外缩放越过阈值，或点击"本星系群"按钮。
- `GALAXY → STAR_SYSTEM`：点击恒星标记，且该恒星有可探索数据。
- `GALAXY → SOLAR`：点击太阳标记，或屏幕中心在太阳标记附近时缩放越过阈值。
- `STAR_SYSTEM → GALAXY`：返回。
- `SOLAR → GALAXY`：返回。
- `SOLAR → EARTH_MOON`：聚焦地球后继续放大，或点击地球的"进入地月系"按钮。
- `EARTH_MOON → SOLAR`：返回。
- `EARTH_MOON → PLANET`：点击地球或月球，进入行星聚焦。
- `PLANET → EARTH_MOON` 或 `PLANET → SOLAR`：按返回键，根据来源决定。
- 任意层级 → `LOCAL_GROUP`：只有通过"宇宙地图"按钮直接跳转，需二次确认，避免误触。

非法转移一律忽略，并在控制台输出一条警告，不弹窗打断用户。过渡进行中（`phase === TRANSITION`）拒绝新的层级切换，但允许相机输入排队；排队最多保留一个目标，避免快速连点导致状态错乱。

### 3.4 相机模型

相机采用轨道相机（orbit camera），参数为：

- `theta`：方位角，绕 Y 轴，范围 [0, 2π)。
- `phi`：极角，从 +Y 轴算起，范围 [MIN_PHI, π/2]。`MIN_PHI = 0.08`，防止相机翻到极点；`π/2` 表示在银道面内。
- `radius`：相机到目标的距离，范围随层级变化。
- `target`：相机注视点，三维向量。
- `fov`：垂直视场角，默认 55°，内部光带视角可增大到 80°。

每一层有独立的相机参数集：

| 层级 | radius 范围 | 默认 radius | phi 范围 | 平移限制 |
|---|---|---|---|---|
| 本星系群 | 2,000–12,000 | 4,500 | 0.15–1.45 | 目标限制在星系群范围内 |
| 银河系 | 250–7,000 | 3,600 | 0.08–1.50 | 目标限制在银盘半径内 |
| 恒星系统 | 2–500 | 80 | 0.08–1.45 | 目标限制在恒星周围 |
| 太阳系 | 18–950 | 360 | 0.08–1.45 | 目标限制在太阳系范围内 |
| 地月系 | 2–120 | 30 | 0.08–1.45 | 目标限制在地月质心附近 |
| 行星聚焦 | 1–50 | 8 | 0.08–1.50 | 目标跟随行星 |

相机阻尼：`damp = 1 - exp(-dt * 11)`，与现有实现一致。所有输入先写入 `camTargetTheta`、`camTargetPhi`、`camTargetRadius`、`camTargetTarget`，再由阻尼插值到实际值。这样即使帧率波动，手感也稳定。

补间（tween）：当需要精确的相机过渡时（层级切换、深链接跳转、复位），使用 `tweenCam(to, durationMs, ease, followId)`。补间期间禁用用户输入对相机的影响，但允许用户按 `Esc` 取消。补间必须可重入安全：每次启动前清空上一次的完成回调，避免回调堆积导致状态被旧回调覆盖。

一个常见 bug：补间开始时清空 `camTweenDone`，但随后又把新的完成回调 push 进去，导致回调在新补间结束时才执行。修正方式是：补间对象自带 `done` 字段，启动时覆盖旧回调；全局只保留一个活动补间，不维护回调数组。若确实需要多个回调，使用 `Promise` 或 `once` 语义，并确保每个回调只执行一次。

### 3.5 过渡动画规格

过渡动画的目标不是炫技，而是帮助用户理解尺度的变化。每一类过渡都有固定的视觉语言：

**向内推进（zoom-in）**：相机半径缩小，目标点朝新场景中心移动，场景 alpha 从 1 到 0，新场景从 0 到 1。时长 1.2–1.8 秒，缓动函数 `easeInOutCubic`。过渡期间显示"正在进入：太阳系"字样与一个逐渐缩小的比例尺。

**向外拉远（zoom-out）**：相机半径增大，旧场景 alpha 降低，新场景出现。时长 1.4–2.0 秒，缓动 `easeInOutCubic`。向外拉远时，新场景（如本星系群）应先以缩小的形态出现在中心，再扩展到正常尺度，模拟"镜头拉远"而不是"淡入一张图"。

**恒星系统进入（star-dive）**：与向内推进类似，但目标点是某颗恒星，过渡期间显示恒星名称与距离。如果目标恒星没有已知行星，只进入恒星特写（一个发光球体 + 信息面板），不伪造不存在的行星系统。

**地月系进入（earth-moon-dive）**：从太阳系层聚焦地球后，继续放大，镜头以地球为锚点，月球从画面边缘进入轨道。过渡时长 1.0–1.5 秒。过渡期间地球不能消失，必须保持可见，否则用户会失去空间连续性。

**返回（back）**：反向播放进入动画，时长略短（0.8–1.2 秒）。返回后恢复进入前的相机位置与聚焦对象。

过渡期间的全屏遮罩不要用一个不透明的黑幕，而要用一个低透明度的径向渐变，中心透明、边缘变暗，强度最高 35%。全黑遮幕会切断空间连续性，让用户觉得是"换了个网页"。

### 3.6 下钻判定：从"无条件"到"有依据"

这是本卷最关键的一节。旧的 `diveToSolar()` 调用条件必须彻底替换。新的判定分三种输入：

**输入一：点击（pick）**。用户点击屏幕上的对象，用射线或屏幕空间拾取得到对象 id。若 id 是太阳标记，进入太阳系；若 id 是其他恒星标记，进入该恒星系统；若 id 是星系标记（本星系群层），进入该星系；若点击空白，则朝点击方向推进相机，不切换层级。

**输入二：滚轮/缩放键**。当相机半径小于当前层级的 `innerThreshold` 时，不是无条件下钻，而是检查"屏幕中心是否对准某个可进入对象"：

- 对准太阳标记（屏幕距离 < 60 px 或世界距离 < 阈值）→ 进入太阳系。
- 对准其他恒星标记 → 进入该恒星系统。
- 未对准任何对象 → 不切换层级，只允许相机继续缩小到一个最小半径（例如太阳系入口半径的 40%），并显示提示"点击太阳或其他恒星以进入"。

**输入三：双击**。双击空白处朝该点推进；双击可拾取对象时，直接进入该对象层级。双击太阳标记等同于点击太阳标记。

判定的几何实现：

1. 把可进入对象的世界坐标投影到屏幕坐标。
2. 计算屏幕中心 (screenW/2, screenH/2) 到对象屏幕坐标的距离。
3. 取距离最近且在阈值内的对象；若多个对象重叠，按屏幕距离与深度排序，优先近处。
4. 阈值随对象类型变化：太阳标记 70 px，普通恒星标记 50 px，星系标记 80 px。
5. 若相机半径已经小于最小半径，仍未对准对象，则不再缩小，并显示提示。

这解决了"放大只能到太阳系"的问题：用户可以点击南门二、巴纳德星、天狼星等标记进入各自的恒星系统；可以点击任意空白区域继续观察银河；可以向外拉远进入本星系群。太阳只是众多入口之一，而不是唯一入口。

### 3.7 缩放入口与手感

缩放有四个入口：滚轮、触屏捏合、`+`/`-` 键、双击/点击推进。它们的语义必须一致：

- 滚轮：以相机目标为中心，按比例缩放。每格滚轮缩放因子 1.12，连续滚动时累加但限制在每帧 1.05–1.25 之间。
- 捏合：按两指距离比例缩放，比例变化直接映射到半径，限制每帧 0.7–1.4。
- `+`/`-`：每按一次缩放 1.18 倍，长按连续触发时限速为每秒 8 次。
- 双击/点击：推进到目标点，推进距离由目标点与相机的距离决定，不直接改变层级；层级切换由 3.6 节的判定负责。

缩放的"软边界"：当半径接近当前层级的 `minR` 或 `maxR` 时，增加阻尼，让用户感觉到"到头了"，而不是硬停。软边界的实现：

```
effectiveRadius = minR + (maxR - minR) * softMap(t)
softMap(t) = t < 0.5 ? ... : ...
```

一个简单可用的公式是：当半径进入边界的最后 15% 区间时，实际缩放量乘以 `0.2 + 0.8 * (1 - overshoot)`，让越界的手感变黏。超过边界的请求不直接丢弃，而是以 10% 的比例缓慢逼近，给用户"还能再挤一点"的反馈，但不会真的越界。

### 3.8 比例尺与空间连续性

每次层级切换、每次相机半径变化超过 2 倍，都要更新比例尺提示。比例尺格式：

- 本星系群：`1 格 ≈ 100 万光年`
- 银河系外侧：`1 格 ≈ 10,000 光年`
- 银河系内侧：`1 格 ≈ 1,000 光年`
- 恒星系统：`1 格 ≈ 1 光年`
- 太阳系：`1 格 ≈ 1 AU`
- 地月系：`1 格 ≈ 100,000 千米`

比例尺放在屏幕左下角，随视角淡入淡出，不遮挡主体。切换层级时，比例尺先显示旧值，再平滑过渡到新值，持续 1 秒，让用户看到"尺度变了"。

空间连续性还有两个细节：

第一，进入新层级时，旧层级的锚点对象应以缩小的形态保留在画面中 0.5 秒，再淡出。例如从银河进入太阳系时，太阳标记先缩小成一个亮点，再消失；从太阳系进入地月系时，地球先缩小成一个蓝色圆点，再成为新场景的主体。

第二，返回时，新（旧）层级的锚点对象从中心放大出现，而不是整屏淡入。这能让用户保持"我从哪里来"的空间记忆。

### 3.9 边界情况与错误处理

**快速连点**：过渡期间最多排队一个目标。第二个请求到达时，如果与当前排队目标相同则忽略；不同则替换排队目标，并在当前过渡结束后执行。禁止并行启动两个补间。

**缩放越界**：相机半径被夹在 `[minR, maxR]`，但补间目标可能越界。补间开始时对目标做 clamp，并在结束时再次 clamp。

**对象未加载**：点击一个尚未生成数据的恒星系统时，显示"该恒星系统的详细数据尚未加载"，并停留在当前层级，不进入空白场景。

**WebGL 上下文丢失**：监听 `webglcontextlost`，暂停渲染，显示提示；监听 `webglcontextrestored`，重建缓冲区与纹理，恢复相机状态。恢复失败时提供"重新加载"按钮。

**深链接非法**：哈希中的层级或对象 id 不存在时，忽略深链接，回退到默认银河视角，并在控制台警告，不弹窗。

**返回栈为空**：按 `Esc` 时若无法返回，执行"复位视角"而不是报错。

**移动端手势冲突**：单指拖动旋转，双指捏合缩放，双指平移。三指及以上忽略。触摸结束时清空手势状态，避免残留速度导致漂移。

### 3.10 深链接与状态同步

深链接格式扩展为：

```
#localgroup                  本星系群
#galaxy                      银河系默认视角
#galaxy/edge                 银河侧视光带
#galaxy/inside               从太阳看银河
#star/alphacen               南门二三合星系统
#star/barnard                巴纳德星
#star/sirius                 天狼星
#solar                       太阳系
#earthmoon                   地月系
#body/earth                  聚焦地球
#body/moon                   聚焦月球
#galaxy/r1200                银河视角半径 1200
#galaxy/arm/perseus          聚焦英仙臂标签
```

状态同步使用 `history.replaceState`，不产生历史记录。只有用户主动点击"返回"时才使用 `history.back()` 或栈内返回。页面监听 `hashchange`，支持用户手动修改地址栏。

深链接的优先级：启动时解析哈希；若合法且数据已加载，直接进入目标层级（跳过动画，或播放一个 0.8 秒的快速过渡）；若不合法，回退默认。深链接进入后，返回栈至少包含一个"银河系默认"条目，避免用户无路可退。

### 3.11 本卷验收标准

交互验收：

1. 在银河层任意位置缩放到最小半径，若屏幕中心没有对准太阳或其他恒星标记，不得进入太阳系。
2. 点击太阳标记进入太阳系；点击南门二标记进入南门二恒星系统；点击空白处只推进相机，不切换层级。
3. 从银河层向外拉远，越过阈值进入本星系群；在本星系群点击银河系，返回银河层。
4. 在太阳系聚焦地球后继续放大，进入地月系，地球保持可见，月球轨道出现。
5. 快速连续点击不同对象，不出现状态错乱、黑屏或相机卡死。
6. 返回栈正确恢复相机位置、聚焦对象与深链接。
7. 深链接 `#galaxy/inside`、`#star/sirius`、`#earthmoon` 均可直接进入对应状态。

代码验收：

1. 全项目搜索不到无条件调用 `diveToSolar()` 的代码路径；所有层级切换都经过 `transitionTo()` 与对象判定。
2. 状态机不存在 `state = ST.X` 的直接赋值（除初始化），层级变化统一走转移函数。
3. 每个层级有独立的相机参数表，半径与极角范围不与相邻层级冲突。
4. 比例尺在层级切换后 1 秒内更新，且数值与当前相机半径匹配。

6. WebGL 上下文丢失/恢复有处理，不导致页面白屏。
