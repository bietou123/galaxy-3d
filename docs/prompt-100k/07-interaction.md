# 第七卷　交互系统、拾取、手势与 UI 规格

> 用户说"点击一块地方可以放大""看清后可以点击某个行星""银河系不能 x 轴 y 轴拖动"。这三句话定义了交互的三条底线：点击必须有意义、点击必须有回应、视角必须能自由但可控地转动。本卷把这些要求展开成可实现的规格，覆盖鼠标、触屏、键盘、标签、面板、演示模式与无障碍。

---

### 7.1 交互设计总原则

1. **所见即可点。** 屏幕上任何一个有名有姓的对象（星系、恒星、行星、月球、旋臂），都应该能点开资料。点了空白处，不弹任何错误提示，只朝那个方向推进视角。
2. **点击与拖动必须分离。** 按下到抬起之间移动超过 6 像素，判定为拖动，不触发点击；少于 6 像素且持续时间少于 400ms，判定为点击。触屏阈值放宽到 10 像素。
3. **旋转不设死锁。** 银河层禁止"只能水平拖"或"只能垂直拖"这类限制。用户要能在任意方向环绕观察，唯一的约束是极角不穿越极点（避免万向节锁与画面翻转）。
4. **反馈必须即时。** 悬停高亮、按下缩放、点击选中，都要在下一帧内出现。不允许"点了没反应"。
5. **每一层的手势语义一致。** 无论在银河、太阳系还是地月系，单指/左键拖动都是旋转，滚轮/双指都是缩放，双击都是推进。不要在不同层级发明新手势。
6. **误触要可撤销。** 进入错误层级后，`Esc` 或"返回"一键回到上一状态，且相机位置恢复。

### 7.2 相机操作：旋转、平移、缩放

**旋转**（最常用）：

- 鼠标左键按下并拖动：水平拖动改变 `theta`，垂直拖动改变 `phi`。
- 灵敏度随相机半径自适应：`dTheta = -dx * 0.005`，`dPhi = -dy * 0.005`。这个系数不随半径变化，因为轨道相机旋转是纯角度操作，与距离无关。若用户觉得过快，可在设置中调"旋转灵敏度"0.5×–2×。
- `phi` 限制在 `[0.08, π/2 - 0.02]`（外部视角）或 `[0.08, 1.50]`（内部光带视角）。不允许 `phi > π/2`，否则相机穿到盘面下方，画面上下颠倒。
- 旋转带阻尼：目标角度写入 `targetTheta`、`targetPhi`，实际角度每帧向目标插值，`damp = 1 - exp(-dt * 11)`。松手后有轻微的惯性收尾，但不做长距离惯性滑动（容易失控）。

**平移**：这是用户说"不能 x 轴 y 轴拖动"时真正想要的自由。

- 鼠标右键拖动，或中键拖动，或 `Shift + 左键拖动`：平移相机注视点。
- 平移在相机平面内进行，使用相机右向量 `r` 与上向量 `u`：
  ```
  k = 2 * tan(fov/2) * radius / screenHeight
  target += (-r * dx + u * dy) * k
  ```
- 平移必须限制在当前层级的合理范围内，防止用户把银河拖出视野。银河层限制在盘半径 2,500 wu 的圆内；太阳系层限制在 900 wu 内；地月系限制在 200 wu 内。
- 平移不是"移动相机"，而是"移动注视点"，相机位置由注视点 + 球坐标重新计算。这样旋转中心始终跟随用户关注的位置。
- 触屏双指平移：两指同时移动，取质心位移映射到 `dx, dy`。

**缩放**：

- 滚轮：`radius *= 1.12^(deltaY/100)`，并夹在 `[minR, maxR]`。
- 触屏捏合：半径乘以 `prevPinchDist / currentPinchDist`，每帧限制在 0.7–1.4。
- `+`/`-` 键：每次 1.18 倍。
- 缩放是"朝注视点缩放"：相机位置沿 `(eye - target)` 方向移动，注视点不变。这就是用户期待的"点击一块地方可以放大"的前提——先把注视点移过去，再缩放，就能聚焦到那个区域。
- 双击空白：把注视点平滑移动到双击射线与银盘的交点，然后缩小半径到当前的 55%。

**双击推进**：

- 双击可拾取对象：直接聚焦该对象（相机补间到对象旁，半径 = 对象视觉半径 × 4），显示资料面板。
- 双击空白：平移注视点 + 缩小半径，不切换层级。
- 双击太阳标记：进入太阳系。
- 双击行星：进入该行星的聚焦状态；地球的双击进入地月系。

### 7.3 拾取系统

拾取分两类：屏幕空间拾取与射线拾取。

**屏幕空间拾取**（用于标记与小天体）：

1. 每帧为所有可拾取对象计算屏幕坐标 `(sx, sy)` 与屏幕半径 `sr`。
2. 点击时遍历对象，计算点击点到 `(sx, sy)` 的距离。
3. 若 `distance < max(sr, minPickRadius)`，则命中；`minPickRadius` 太阳为 22px、恒星 16px、行星 12px、星系标签 20px。
4. 多个命中时，按深度（相机空间 z）从近到远排序，取最近的；若深度接近（相差 < 5%），取屏幕距离更近的。
5. 位于相机背后（`clip.w <= 0`）的对象不参与拾取。

**射线拾取**（用于盘面与空白推进）：

1. 把点击点转换为 NDC，再乘以逆投影逆视图矩阵，得到世界空间射线。
2. 与银盘平面 `y = 0` 求交，得到世界点。这与现有 `galaxyPointAt(px, py)` 一致，扩展时要保证矩阵正确求逆。
3. 交点在盘半径内，则作为新的注视点候选；否则忽略。
4. 本星系群层没有明确的平面，可以用"距离相机最近的星系代理"作为拾取目标，或干脆只允许屏幕空间拾取。

**悬停**：

- 鼠标移动时每 80ms 做一次拾取（不要每帧做，浪费 CPU）。
- 命中后：对象标记放大 1.3 倍并显示外圈，鼠标指针变为 `pointer`，屏幕上方显示该对象的一行摘要（名称 + 关键参数）。
- 未命中：清除高亮，恢复默认指针。
- 触屏没有悬停，跳过。

**拾取的可访问性**：

- 标记在屏幕上太小时，提供一个不可见的扩大命中区域（至少 16px 直径）。
- 键盘用户可以用 `Tab` 在可拾取对象间切换，`Enter` 选中。焦点对象有明确的焦点框。
- 侧栏列表中的每个对象也是可点击的等价入口，不依赖三维拾取。

### 7.4 键盘操作

| 按键 | 功能 |
|---|---|
| `W` / `↑` | 相机沿视线向前平移 |
| `S` / `↓` | 向后平移 |
| `A` / `←` | 向左平移 |
| `D` / `→` | 向右平移 |
| `+` / `=` | 放大 |
| `-` / `_` | 缩小 |
| `空格` | 暂停/继续时间 |
| `R` | 复位当前层级的相机 |
| `Esc` | 返回上一层级；若无法返回则复位相机 |
| `1` | 俯视视角（银河层） |
| `2` | 侧视光带视角（银河层） |
| `3` | 从太阳看银河（银河层） |
| `L` | 切换标签显示 |
| `G` | 打开/关闭银河结构图例 |
| `H` / `?` | 帮助面板 |
| `P` | 截图（保存 PNG） |
| `F` | 全屏 |
| `Tab` | 在可交互对象间切换焦点 |
| `Enter` | 选中当前焦点对象 |

注意：

- 键盘事件在输入框获得焦点时必须忽略（`event.target.tagName === 'INPUT'`），否则用户输入搜索词会触发相机移动。
- 按住方向键时，第一段延迟 300ms，之后每秒重复 20 次，速度平滑。
- 所有键盘操作都要有对应的按钮，不能只有键盘入口。

### 7.5 触屏手势

- **单指拖动**：旋转。
- **双指捏合**：缩放。
- **双指拖动**：平移。
- **双击**：推进。
- **双指双击**：复位视角（可选）。
- **三指及以上**：忽略，避免误触。

实现要点：

- 使用 `pointerdown` / `pointermove` / `pointerup` / `pointercancel`，而不是同时监听鼠标与触摸事件，减少重复逻辑。
- 记录每个活动指针的 id、起始位置、当前速度。
- 单指 → 双指切换时，重置手势状态，避免第一根手指的位移被误算为捏合。
- `touch-action: none` 加在画布上，阻止浏览器默认的页面滚动与缩放。
- 移动端建议降低旋转灵敏度到 0.7×，因为手指比鼠标更难精细控制。
- 竖屏时，把侧栏收进底部抽屉；横屏时恢复侧栏。

### 7.6 标签系统

标签是 HTML 元素，绝对定位在画布之上，每帧根据投影坐标更新 `transform: translate(x, y)`。不要每帧修改 `left/top`（触发重排），只用 `transform`（合成层）。

标签类型：

- **一级标签**：太阳系、银河核心、四条主旋臂、仙女座星系、三角座星系、大小麦哲伦云。字号 13px，始终显示（可被总开关关闭）。
- **二级标签**：其他恒星、其他矮星系、行星名。字号 11px，条件显示。
- **临时标签**：悬停提示、聚焦对象名。字号 12px。

显示规则：

1. **优先级**：一级 > 二级 > 临时。标签太多时按优先级裁剪。
2. **距离裁剪**：对象在屏幕外、位于相机背后、投影半径小于 1.5px 时隐藏。
3. **重叠规避**：按优先级顺序放置标签，已放置标签占据一个矩形；新标签若与已有矩形重叠，则隐藏（一级标签改为偏移显示，最多偏移两行）。
4. **数量上限**：同时显示不超过 40 个。超出时只保留最近与最高优先级的。
5. **淡入淡出**：层级切换时标签 opacity 过渡 300ms，不要突然全部出现。
6. **缩放联动**：相机拉远到一定距离时，自动隐藏二级标签，避免画面被文字淹没。

标签样式：

- 深色半透明底（`rgba(6, 10, 20, 0.55)`），1px 细边框，圆角 4px，内边距 4px 8px。
- 文字颜色 `#dfe8ff`，副标题 `#8fa3c8`。
- 不做发光、不做描边，避免与星空争抢注意力。
- 高亮状态：边框变为 `rgba(140, 190, 255, 0.9)`，背景略亮。

### 7.7 信息面板

信息面板分三种结构：

**行星/卫星面板**：

- 标题：中文名 + 英文名
- 分类标签：行星 / 卫星 / 矮行星
- 关键参数（两列）：直径、质量、距离、公转周期、自转周期、表面温度、卫星数
- 简介：150–300 字
- 科学注记：值得强调的事实（如金星逆行、天王星躺着转）
- 操作：聚焦、进入下一级（如地球的"进入地月系"）、返回

**星系面板**：

- 标题：中文名 + 编号
- 分类：星系类型
- 参数：距离、直径、恒星数量、质量、所属
- 简介：150–300 字
- 科学注记：如仙女座与银河系的碰撞预测
- 操作：聚焦、进入（银河系可进入 L0）

**恒星面板**：

- 标题：中文名 + 英文名
- 分类：光谱型
- 参数：距离、质量、半径、表面温度、光度、已知行星
- 简介
- 科学注记：如参宿四的尺寸对比

面板布局：

- 桌面端：右侧固定宽度 320–360px，从右滑入，不遮挡画面中心。被点击对象若在右侧，面板改到左侧。
- 移动端：底部抽屉，高度 45vh，可上滑展开、下滑收起。
- 关闭方式：右上角 ×、`Esc`、点击画布空白处。
- 面板打开时，相机仍可操作，但不会因为拖动而关闭面板（只有点击且未拖动才关闭）。

面板的动画时长 240ms，缓动 `easeOutCubic`。内容更新时（切换到另一个对象）不重建面板，只替换文字，避免闪烁。

### 7.8 侧栏与导航

侧栏提供"不依赖三维操作"的导航路径：

- **层级面包屑**：本星系群 / 银河系 / 太阳系 / 地月系，点击任意一段可跳转。
- **本层对象列表**：银河层列出太阳、邻近恒星、四条旋臂；太阳系列出八大行星；地月系列出地球、月球。
- **视图切换**：俯视 / 侧视 / 内部光带（仅银河层）。
- **时间控制**：暂停、0.25×、1×、4×、8×。
- **显示开关**：标签、轨道线、暗尘带、比例尺、网格。
- **画质选择**：自动 / 高 / 中 / 低。

侧栏在小屏幕上默认收起，用左上角按钮展开。侧栏展开时不阻塞画面，宽度 220px，半透明。

### 7.9 图例与比例尺

**图例**（银河层）：

- 中央棒：黄橙色块
- 核球：亮黄点
- 旋臂：蓝白色条
- 猎户臂：淡蓝细条
- 暗尘带：褐色条
- HII 区：粉色点
- 银晕：淡黄点

图例默认收起，点击 `G` 或图例按钮展开。展开时占据左下角，不遮挡主体。

**比例尺**：

- 左下角，一条水平线 + 文字。
- 长度自动选择"好看的"数值：1、2、5 × 10^n。
- 银河层：`1,000 光年`、`5,000 光年`、`10,000 光年`。
- 太阳系：`0.5 AU`、`1 AU`、`5 AU`。
- 地月系：`50,000 千米`、`100,000 千米`、`384,400 千米`。
- 本星系群：`100 万光年`、`500 万光年`。
- 比例尺随缩放实时更新，但文字更新做 200ms 节流，避免数字抖动。
- 比例尺旁边注明"视觉压缩"（若该层级使用了非线性映射），例如太阳系层写"行星大小已放大，轨道距离已压缩"。

### 7.10 演示模式

演示模式用于展示与录屏：

- 按 `D` 或点击"演示"按钮进入。
- 进入后隐藏所有 UI（侧栏、标签、比例尺、帮助按钮），只保留画面与一个极简的退出提示。
- 自动执行一段相机轨迹：从本星系群拉近到银河，绕银河一圈，俯视，再侧视，最后进入太阳系。总时长约 60 秒。
- 轨迹使用关键帧 + 缓动，而不是固定速度线性插值。
- 任意输入（鼠标、键盘、触摸）立即退出演示模式，交还控制权，不打断当前相机位置。
- 演示模式不改变层级状态机的逻辑，只是自动写入相机目标。

截图：

- `P` 键或按钮触发。
- 截图前隐藏 UI（与演示模式一致），绘制一帧干净的画面，调用 `canvas.toBlob` 保存为 PNG。
- 文件名 `galaxy-3d-<layer>-<timestamp>.png`。
- 若浏览器不支持下载，退化为在新标签页打开图片。

### 7.11 帮助面板

帮助面板用 `H` 或 `?` 打开，内容分四组：

- **视角**：左键拖动旋转、右键/Shift+左键平移、滚轮缩放、双击推进。
- **导航**：点击对象查看资料、`Esc` 返回、面包屑跳转。
- **键盘**：列出 7.4 节的快捷键。
- **说明**：银河系是棒旋星系，太阳位于猎户臂；距离与大小如有压缩，会在此说明。

帮助面板首次访问自动弹出一次（可关闭），之后不再自动弹出。移动端帮助面板全屏显示，`Esc`/返回键关闭。

### 7.12 无障碍

- 所有按钮有 `aria-label`，面板有 `role="dialog"` 与 `aria-modal`。
- 焦点框可见，不依赖颜色区分（用 2px 实线 + 外发光）。
- 支持键盘完成所有导航，三维拾取不是唯一入口。
- 颜色对比度：正文文字与背景对比度 ≥ 4.5:1，次要文字 ≥ 3:1。
- 尊重 `prefers-reduced-motion`：开启后禁用相机惯性、禁用演示模式自动播放、过渡时长缩短到 200ms。
- 画布提供一段文本描述（`aria-label` 或隐藏的说明文字），描述当前层级与主要对象。

### 7.13 状态与 URL 同步

- 每次层级变化、聚焦对象变化、视图模式变化，都更新 URL 哈希。
- 使用 `history.replaceState`，不产生历史记录；只有用户主动"返回"才用 `history.back()`。
- 页面加载时解析哈希，恢复状态；非法哈希回退到银河默认视角。
- 用户手动修改地址栏并回车时，监听 `hashchange` 并应用新状态。

### 7.14 移动端适配

- 画布使用 `100dvh` 而不是 `100vh`，避免移动浏览器地址栏导致的跳动。
- 侧栏折叠为底部抽屉，信息面板也是抽屉，两者不能同时展开。
- 标签字号在小屏幕上加 1px，保证可读。
- 触摸目标最小 44×44px（含不可见的扩大区域）。
- 低端设备自动使用 mid 或 low 画质。
- 横屏时隐藏侧栏默认状态，给画面更多空间。

### 7.15 错误与边界

- 点击一个没有资料的对象（如某个无名矮星系光斑）：不打开空面板，改为在屏幕底部显示一行提示"该对象暂无详细资料"。
- 过渡进行中点击对象：忽略点击，不排队拾取，但排队层级切换（最多一个）。
- 长时间无操作（5 分钟）：不自动演示，不自动旋转，保持静止。安静比炫技更合适。
- 页面隐藏（`visibilitychange`）：暂停渲染循环，节省电量；重新可见时恢复。
- 窗口尺寸变化：重建投影矩阵，重新计算像素比，标签重新布局。

### 7.16 本卷验收标准

1. 银河层可以用鼠标左键在任意方向旋转，不受"只能水平/垂直拖"的限制。
2. 右键或 Shift+左键可以平移注视点，平移范围被限制在合理边界内。
3. 点击太阳标记进入太阳系；点击南门二进入恒星系统；点击空白只推进视角。
4. 点击到抬起移动超过 6px 时不触发点击，避免拖动结束误开面板。
5. 悬停有高亮与摘要，拾取延迟不超过 100ms。
6. 标签不重叠、不遮挡面板、数量不超过 40。
7. 面板可以从右侧滑入并在窄屏上变为底部抽屉。
8. 所有键盘快捷键可用，输入框获得焦点时不触发。
9. 演示模式可进入、可被任意输入打断、不改变层级状态。
10. `prefers-reduced-motion` 下动画被显著削弱。
11. URL 哈希与当前状态一致，手动修改地址栏能跳转。
12. 移动端单指旋转、双指缩放、双指平移均正常，无页面滚动穿透。

### 7.17 实现回改记录

按总纲 0.6，P7 落地时对本卷条款的调整与补充集中记在这里，代码与本文以本节为准。

1. **快捷键：H 给演示，帮助改用 `?` / `/`**。7.10 写 `D` 进入演示、7.11 写 `H` 打开帮助，两者在实际操作中都和「演示」这一最常用动作冲突：用户更习惯按 H 看到自动巡游，而帮助面板一开就打断观看。落地为 `H` 切换演示（再按一次退出，`Esc` 也退出），帮助用 `?` 或 `/` 打开；没有 `D` 快捷键。`P` 键截图同样没有做，截图入口是工具栏的相机按钮。
2. **演示轨迹是帧驱动的时间轴，不用定时器**。各层 `enter/exit` 一开头都会 `clearTimers()`，用 `later()` 排的后续步骤会被下一次转场一起清掉。实现改为 `updateDemoTour(dt)` 按帧累计：1.6 秒进入本星系群，12.8 秒返回银河，16.5 / 27 / 34 秒切俯视、侧视、盘内，41 秒进入太阳系，60 秒结束。第一步留 1.6 秒而不是 0.6 秒，观众先看清当前视角，也给「任意操作退出」留出不会撞上转场的窗口 —— P7 验收最初在 0.6 秒版本上偶发失败，就是输入刚好落在转场开始之后。
3. **进入演示本身不改层级，巡游按脚本改**。7.16 第 9 条「不改变层级状态」约束的是进入/退出这个动作：`setDemo(true)` 只隐藏界面、排出巡游，不调用任何 `enter*`；退出也不重置相机或层级。巡游中按时间表下钻、返回属于 7.10 的设计内容。退出演示时同时清空按住的平移键，否则相机会朝一个方向持续漂移。
4. **URL 哈希只在能解释当前状态时应用**。7.13 要求「手动修改地址栏并回车时应用新状态」，实现收敛为：`#solar`、`#localgroup`、`#star/...` 只在银河层触发下钻；`#body/...`、`#localgroup/...`、`#earthmoon/...` 可在对应层内切换聚焦对象。当前层级无法解释的哈希直接忽略，不硬跳 —— 否则用户在地月系里手滑改地址栏，会被直接切断送回太阳系。非法 id 静默忽略，不报错。
5. **网格开关未实现**。7.9 的显示开关原列「标签、轨道线、暗尘带、比例尺、网格」，落地的四个开关不含网格：银河盘面的经纬网格在暗背景上会盖住旋臂与暗尘，尺度提示交给比例尺和轨道线更清楚。比例尺文字按 200ms 节流，条形宽度每帧跟手，与 7.9 一致。
6. **点击判定阈值 8px**。7.16 第 4 条写 6px，实测触屏拖动时 6px 太敏感，手指轻微移动就会被当成点击，误开面板；落地为 8px。转场进行中忽略点击，但不排队拾取；层级切换最多排队一个。
7. **演示的被动画幅**。`prefers-reduced-motion: reduce` 下不排巡游（`demoTour = null`），只隐藏界面并提示「系统已禁用自动巡游」；界面过渡时长压到接近瞬时，与 7.12 一致。
8. **截图文件名**。7.10 写 `galaxy-3d-<layer>-<timestamp>.png`，实现用 `milkyway-YYYYMMDD-HHMMSS.png`：文件名里不带层级，方便把不同层的截图放进同一个文件夹按时间排序；调用 `canvas.toBlob` 在绘制完成的同一帧取图，不需要 `preserveDrawingBuffer`。

### 7.18 P9 优化回改记录（2026-11-14）

1. **跨层搜索**：结果直接来自 `SUN` / `PLANETS` / `GALAXIES` / `STARS` 及系内行星，不编造天体。支持中文、英文、目录编号、全角输入与空格/连字符归一化，保留候选行星标记。搜索用现有逐层导航队列推进，连续选择覆盖旧目标；用户操作可取消剩余步骤，已经开始的转场正常完成。旧深链接与返回地球的延迟聚焦不能覆盖新搜索。
2. **输入隔离与可访问性**：搜索用 combobox / listbox 与活动选项标记；方向键选择、Enter 前往、Esc 清空，IME 确认不导航。Ctrl/Cmd+K 展开导航并聚焦。输入控件获得焦点后清空按住的移动键，输入不触发暂停、演示或层级退出。
3. **自动画质与偏好**：自动、高、中、低四种模式。自动从高档开始，预热约 1.2 秒，以至少 1.5 秒且至少 12 帧的窗口持续采样真实帧间隔，只降不升；手动档锁定。模式以带版本的 JSON 保存，URL 优先但不覆盖偏好，非法值或不可用存储安全回退。实际银河粒子预算为高 340,000、中 204,000、低约 119,000，旧 `CFG.build` 中三档预算不参与当前绘制。
4. **响应式布局与取景**：工具栏位置由 ResizeObserver 测得的真实面板高度决定，不再固定按 40vh 抬高。短屏工具栏横向滚动，横屏导航合并成紧凑行；资料内容独立滚动，关闭按钮留在外层。移动端投影中心对齐剩余画面区域，聚焦天体保持可见；拾取、银盘点击反投影、平移与比例尺使用同一投影。小屏太阳下钻尺寸阈值跟随投影缩放，最低 20px，桌面保留 70px；中心对齐条件不变。FOV 和 near 变化时及时刷新投影。
5. **页面可见性**：隐藏时跳过绘制与模拟；恢复时重置帧时间与采样预热，不把隐藏期间的空档计入物理推进或自动降档。
6. **验收结果**：`tools/acceptance_p9.py` 新增 173 项无头 Chromium 验收，加上冒烟与 P3–P7 的 251 项，共 424 项通过、0 失败。画质策略使用合成 rAF 时间戳验证阈值，不是 GPU 跑分；真实渲染检查覆盖画布非空、动画、拖动、手机投影与点击往返、紧凑屏太阳下钻、聚焦天体可见和资料关闭按钮。Firefox、Safari 与移动端真机性能仍待补验。
