# 附录　术语、分类、单位、数据来源与常见误解

> 前三卷已经在正文里使用了大量天文学名词。如果读者不知道 "SBbc" 每个字母的含义，或者不清楚 "kpc" 与 "光年" 的换算，正文的参数就会变成一串无意义的数字。本附录补齐这些基础，并说明数据从哪里来、哪些是估计、哪些仍有争议。

### A.1 银河系结构术语

**银心（Galactic Center）**：银河系几何与动力学中心，方向在人马座，被大量尘埃遮挡，需用红外、射电与 X 射线观测。中心存在一个超大质量黑洞，即人马座 A*（Sagittarius A*），质量约 415 万倍太阳质量。2022 年，事件视界望远镜公布了它的首张图像。

**核球（Bulge）**：银心周围恒星密集的区域，半径约 1–2 kpc。银河系的核球不是标准椭球，而是被中央棒贯穿的"花生状"或"盒子状"结构。核球以年老恒星为主，颜色偏黄红。

**中央棒（Central Bar）**：贯穿核球的三轴结构，半长轴约 4–4.5 kpc，方位角相对太阳—银心连线约 20°–30°。棒是 SB 型星系的分类依据。棒不是静止的固体，其中的恒星沿棒内轨道运动，棒本身以较慢的图样速度旋转。

**薄盘（Thin Disk）**：银河系主要恒星与气体所在的盘，标高约 300 pc，包含大部分年轻恒星、疏散星团、HII 区与分子云。太阳位于薄盘内，距盘中面约 20–30 pc。

**厚盘（Thick Disk）**：比薄盘更厚、更年老的恒星成分，标高约 1,000–1,500 pc，金属丰度较低，运动学上更"热"。厚盘的存在让侧视的银河盘边缘呈现柔和雾状，而不是一条硬线。

**旋臂（Spiral Arm）**：盘内恒星与气体密度较高的波状结构，不是固定的物质臂，而是密度波或动态图样。银河系公认有四条主旋臂：英仙臂（Perseus Arm）、人马—船底臂（Sagittarius–Carina Arm）、矩尺臂（Norma Arm）、盾牌—半人马臂（Scutum–Centaurus Arm）。

**猎户臂（Orion Arm / Local Arm）**：位于人马臂与英仙臂之间的次级臂段，太阳位于其内缘。长度约 5–8 kpc，比主旋臂短而细。猎户臂上包含猎户座大星云等著名恒星形成区。

**银晕（Galactic Halo）**：盘之外的球状分布成分，包含年老恒星、球状星团与暗物质。可见恒星的密度按半径近似 r^-3 衰减。银晕中的恒星金属丰度低，年龄大。

**银冕 / 暗物质晕（Galactic Corona / Dark Matter Halo）**：银晕之外的扩展成分，主要由暗物质构成，可见物质很少。银河系的总质量估计很大程度上依赖暗物质晕的范围与质量分布，不同方法给出的结果差异较大。

**本地泡（Local Bubble）**：太阳附近一个直径约 300 pc 的低密度热气体区域，由历史上的超新星爆发吹出。太阳目前位于这个泡的内部或边缘。这解释了为什么太阳附近星际介质密度偏低。

**太阳邻域（Solar Neighborhood）**：距太阳约 100 pc 内的区域，是恒星普查最完整的部分。邻近恒星表（第五卷）主要来自这个范围。

**大裂缝（Great Rift）**：从天鹅座延伸到人马座的一条暗尘带，把夏季银河的光带分成两半。它由银盘内的尘埃云造成，是"从太阳看银河"视角最重要的识别特征。

**61 秒差距问题 / 银河系尺度争议**：历史上对银河系大小的估计从几千光年到十万光年不等，直到二十世纪才逐步收敛。这说明"银河系多大"本身是一个观测史问题，不是一句定论。

### A.2 星系分类：哈勃序列与 SBbc

哈勃分类（Hubble Sequence）把星系分为椭圆星系（E）、透镜星系（S0）、旋涡星系（S）、棒旋星系（SB）和不规则星系（Irr）。旋涡与棒旋再按旋臂的紧密程度细分为 a、b、c：

- **Sa / SBa**：核球大，旋臂紧密缠绕，气体少，恒星形成弱。
- **Sb / SBb**：核球中等，旋臂中等张开。
- **Sc / SBc**：核球小，旋臂松散，气体多，恒星形成活跃。
- **Sd / SBd**：旋臂极松散，接近不规则。

**SBbc** 的含义：

- `S` = 旋涡星系（Spiral）
- `B` = 有中央棒（Barred）
- `b` = 旋臂中等缠绕（介于 a 与 c 之间）
- `c` = 另一个 b→c 之间的过渡标记，表示比典型 Sb 更松散一些

所以银河系是"中等缠绕的棒旋星系"。这也是为什么模型里必须画中央棒——否则分类就不成立。

**M31 的 SA(s)b**：

- `S` 旋涡
- `A` 无棒（unbarred），括号表示"按旧分类曾被认为无棒"
- `(s)` 旋臂形态为 s 型（S 形），而不是 r 型（环状）
- `b` 中等缠绕

近年有研究认为 M31 可能存在弱的棒结构，所以分类也有争议。模型里可以画一条不明显的棒，或不画，并在面板注明"结构分类存在争议"。

**M33 的 SA(s)cd**：无棒，旋臂极松散，恒星形成活跃，絮状（flocculent）旋臂。

**LMC 的 SB(s)m**：有棒，magellanic 型（麦哲伦型），单臂或不对称的旋涡结构。

**dSph**：矮椭球星系（dwarf Spheroidal），低表面亮度，年老恒星为主，几乎没有气体。人马座矮椭球与天龙座矮星系都是这一类。

### A.3 天文学单位与换算

| 单位 | 定义 | 换算 |
|---|---|---|
| AU（天文单位） | 地球到太阳的平均距离 | 149,597,870.7 km |
| 光秒 | 光在真空中 1 秒走的距离 | 299,792.458 km |
| 光年（ly） | 光在真空中 1 儒略年走的距离 | 9.4607 × 10^12 km |
| 秒差距（pc） | 视差 1 角秒对应的距离 | 3.2616 光年 = 206,265 AU |
| 千秒差距（kpc） | 1,000 pc | 3,261.6 光年 |
| 百万秒差距（Mpc） | 10^6 pc | 326 万光年 |
| 太阳质量（M☉） | 太阳的质量 | 1.989 × 10^30 kg |
| 太阳半径（R☉） | 太阳的半径 | 696,340 km |
| 太阳光度（L☉） | 太阳的光度 | 3.828 × 10^26 W |

常用换算速记：

- 1 kpc ≈ 3,260 光年。
- 银河系直径 26.8 kpc ≈ 87,400 光年。
- 太阳距银心 8.2–8.3 kpc ≈ 26,700–27,000 光年。
- 本星系群直径约 3 Mpc ≈ 1,000 万光年。
- M31 距离 2.54 Mly ≈ 780 kpc。
- 地月距离 384,400 km ≈ 1.28 光秒 ≈ 0.00257 AU。

**世界单位 wu 的映射**（第一卷 1.10 节）：

- 银河层：1 wu = 20 光年。盘半径 2,500 wu = 5 万光年半径（直径 10 万光年）。
- 本星系群层：1 wu = 1,000 光年。M31 位于 2,540 wu。
- 太阳系层：非线性映射，`r = 30 × AU^0.55`，不是线性比例。
- 地月系层：1 wu = 1 个地球半径（6,371 km）。

这些映射是视觉设计决策，不是物理比例尺。任何阅读代码的人看到 "1 wu" 都必须先看当前层级，否则会误解。

### A.4 数据来源与可信度分级

本项目的数据分为三级：

**一级（高可信）**：来自空间任务与权威机构的公开数据，例如 NASA 的行星事实页、IAU 的命名与分类、ESA Gaia 任务的恒星测量、事件视界望远镜的 Sgr A* 结果。这类数据可以直接进入 UI，不需要加"估计"。

**二级（可靠但有范围）**：来自大型巡天论文与综述，例如银河系棒的长度、旋臂的螺距角、本星系群成员的数量。不同论文给出的值有区间，模型取常用中值，并在面板写"约"或区间。

**三级（估计或争议）**：例如银河系恒星总数的量级、矮星系的质量、比邻星 c 是否存在、X 形核球结构。这类内容必须明确标注"估计""候选""存在争议"，不能当作确定事实呈现。

数据引用规范：

- UI 面板不写论文编号，只写数值与"约"。
- README 的"科学说明"章节列出主要参考类型，不逐条列参考文献。
- 代码中的数据表用注释说明该行数据的性质（一级/二级/三级）。
- 不复制受版权保护的长段文字；介绍文案为原创撰写。

**禁止的数据行为**：

- 不为不在目录中的天体编造名字与数据。
- 不把估计值写成精确值（例如写"银河系有 2000 亿颗恒星"而不加"约"）。
- 不把未来预测写成既定事实（例如"45 亿年后一定会合并"应写"可能"）。
- 不混用不同来源的单位（例如把 kpc 与光年直接相加）。

### A.5 常见误解问答

**问：银河系是什么颜色？**

答：整体偏白，核球偏黄，旋臂因年轻蓝星而偏蓝白，暗尘带呈褐色。肉眼看到的是明暗与微弱的色调差异，不是照片里那种高饱和的紫蓝色。模型里的颜色应接近"柔和的白 + 局部黄蓝对比"，而不是荧光色。

**问：银河系有多少颗恒星？**

答：常用估计是 1,000 亿到 4,000 亿颗。差异来自统计方法与对盘外缘、暗弱恒星的推断。任何精确到个位的数字都是不严谨的。

**问：太阳绕银心一圈要多久？**

答：约 2.25–2.5 亿年，称为一个"银河年"。太阳的轨道速度约 220–230 km/s。由于太阳在盘内并非匀速运动，不同文献给出的周期略有差异。

**问：银河系中心是黑洞吗？**

答：中心是超大质量黑洞人马座 A*，但它只占中心质量的一小部分，核球的绝大部分质量是恒星与气体。黑洞本身不发光，我们看到的是周围物质的辐射。

**问：为什么从地球看银河是一条带？**

答：因为太阳位于银盘内部，银盘是一个扁平的盘状结构。当我们沿着盘面方向看过去时，盘内的恒星在视线方向上叠加，形成一条横贯天空的光带。如果太阳在盘外，我们会看到一个旋涡，而不是一条带。这正是模型提供"俯视 / 侧视 / 内部"三种视角的原因。

**问：银河系是长条的吗？**

答：从正面看是个旋涡盘，从侧面看是一条细长的带，从内部看是一条横贯天空的光带。"长条"是侧视与内部视角的正确观感，但俯视时仍然是圆的旋涡。模型必须能切换这三种视角，否则用户会误以为银河系只有一种形状。

**问：暗物质看得见吗？**

答：看不见。我们通过恒星与气体的运动速度、引力透镜、星系团的动力学推断它的存在。模型不渲染暗物质，可以在信息面板中提及。

**问：M31 会撞上银河系吗？**

答：目前的观测与模型认为约 45 亿年后可能发生碰撞与合并，但具体时间与细节存在不确定性。恒星之间直接相撞的概率极低，但两个星系的结构会彻底改变，最终可能形成一个巨大的椭圆星系。

**问：大小麦哲伦云是银河系的一部分吗？**

答：不是。它们是银河系的卫星星系，位于银河系之外，距离约 16–20 万光年。它们被银河系的引力束缚，正在被潮汐扰动。

**问：月球为什么总是同一面朝向地球？**

答：因为月球的自转周期与公转周期相同（都是 27.32 天），称为潮汐锁定。这不是巧合，而是长期潮汐作用的结果。由于天平动，地球上实际可见的月面约 59%。

**问：月球在远离地球吗？**

答：是的，约 3.8 厘米/年。潮汐作用把地球的自转角动量传递给月球的轨道，使月球缓慢远离，同时地球自转变慢、日长增加。

**问：为什么太阳系模型中行星大小和距离不成比例？**

答：真实比例下，如果太阳是 1 厘米，地球在 1 米外，几乎是个看不见的尘埃，画面将无法使用。所以模型使用非线性映射：放大了行星的相对大小，压缩了外侧轨道距离。这必须在比例尺旁标注，否则会误导。

**问：为什么邻近恒星在银河系中的位置被放大了？**

答：4–25 光年的距离相对于 10 万光年的银河系直径几乎为零。如果按真实比例，所有邻近恒星都会与太阳标记重叠。模型把它们沿一个人工放大区排列，并用虚线连接，图例说明"距离已放大"。

**问：银河系里有"X 形"结构吗？**

答：部分研究认为核球存在 X 形或盒子状结构，但并非所有观测都支持。模型默认低强度显示，并在面板注明争议。

**问：为什么不用真实的星空照片贴图？**

答：第一，会涉及版权；第二，贴图在三维中旋转、缩放的观感很差；第三，无法交互。程序化生成保证了零依赖、可复现、可交互三点。

### A.6 银河系认识的简史

理解这段历史，有助于理解为什么模型里的某些参数有区间。

**1610 年**：伽利略用望远镜发现银河由无数暗星组成。

**1785 年**：威廉·赫歇尔通过恒星计数绘制第一张银河系"扁平盘"模型，太阳被认为接近中心。

**1920 年**：沙普利与柯蒂斯就"旋涡星云是否在银河系之外"展开大辩论。

**1924 年**：哈勃在仙女座星系中观测到造父变星，测定距离，确认河外星系的存在。

**1930 年代**：射电观测发现银河系的中性氢分布，为旋臂结构提供证据。

**1950 年代**：光学与射电观测确认银河系的旋臂结构，太阳被发现位于盘内而非中心。

**1990 年代–2000 年代**：红外巡天（COBE、2MASS）穿透尘埃，确认中央棒结构。

**2005 年前后**：斯皮策空间望远镜的红外数据给出更清晰的棒结构与核球形态，棒长度与方位角的估计逐步收敛到 4–4.5 kpc 与 20°–30°。

**2013 年至今**：Gaia 任务精确测量数十亿颗恒星的位置与运动，重构银河系的三维结构与演化历史，同时不断修正旋臂与太阳距离的数值。

这段历史说明：银河系的结构参数不是"查表可得"的固定值，而是逐步收敛的观测结果。模型采用常用中值，并在文档中标注区间，是对科学不确定性的尊重。

### A.7 从观测数据到三维模型的取舍

把银河系变成可交互的三维模型，必然要做取舍：

**逐星建模不可行。** 银河系有上千亿颗恒星，模型只有几十万粒子。粒子代表的是恒星群的统计分布，不是个体。

**旋臂用对数螺旋近似。** 真实旋臂是密度波与动态图样，形态不规则、有分支与断点。对数螺旋是数学近似，能让"结构可读"，但不应被误解为精确测绘。

**盘的厚度被适度夸张。** 真实薄盘非常薄，侧视时接近一条线。为了在侧视图中看到厚度与核球，模型需要在视觉上放大垂直尺度，同时在文档中说明。

**颜色是统计编码。** 粒子颜色代表该区域恒星的典型颜色/年龄，不是每颗星的真实光谱。

**时间被压缩。** 银河自转周期 1.8 亿–2.4 亿年，模型中用几十秒表示；地月系的月球公转用几十秒表示。时间压缩必须在 UI 中标注。

**距离被压缩。** 银河层用 1 wu = 20 光年，本星系群用 1 wu = 1,000 光年，太阳系用非线性映射。每一层都要有独立的比例尺。

这些取舍不是缺陷，而是可视化的必要手段。唯一的错误是"做了取舍却不告诉用户"。
